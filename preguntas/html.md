# Cuestionario de HTML

**1.** ¿Qué etiqueta se usa para crear un enlace?
- A) `<img>`
- B) `<a>`
- C) `<p>`
- D) `<link>`

Respuesta: B

**2.** ¿Qué etiqueta crea el título más grande de una página?
- A) `<h6>`
- B) `<title>`
- C) `<h1>`
- D) `<head>`

Respuesta: C

**3.** ¿Qué etiqueta se usa para mostrar una imagen?
- A) `<img>`
- B) `<image>`
- C) `<pic>`
- D) `<src>`

Respuesta: A

**4.** ¿Qué etiqueta crea una lista con viñetas?
- A) `<ol>`
- B) `<ul>`
- C) `<li>`
- D) `<list>`

Respuesta: B

**5.** ¿Qué etiqueta se usa para crear un formulario?
- A) `<input>`
- B) `<table>`
- C) `<div>`
- D) `<form>`

Respuesta: D

**6.** ¿Qué significan las siglas HTML?
- A) HyperText Markup Language
- B) High Text Machine Language
- C) Home Tool Markup Language
- D) HyperTransfer Mark Language

Respuesta: A

**7.** ¿Qué etiqueta se usa para escribir un párrafo?
- A) `<par>`
- B) `<text>`
- C) `<p>`
- D) `<paragraph>`

Respuesta: C

**8.** ¿Qué etiqueta da un salto de línea?
- A) `<lb>`
- B) `<break>`
- C) `<nl>`
- D) `<br>`

Respuesta: D

**9.** ¿Qué etiqueta se usa para crear una tabla?
- A) `<tr>`
- B) `<table>`
- C) `<td>`
- D) `<grid>`

Respuesta: B

**10.** ¿Cuál es la forma correcta de crear un botón de opción (radio)?
- A) `<input type="radio">`
- B) `<input type="check">`
- C) `<radio>`
- D) `<select type="radio">`

Respuesta: A
