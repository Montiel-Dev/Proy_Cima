# Cuestionario de Python

**1.** ¿Qué función se usa para mostrar datos en pantalla en Python?
- A) echo
- B) print()
- C) console.log()
- D) printf

Respuesta: B

**2.** ¿Cuál es la extensión correcta de un archivo de Python?
- A) .py
- B) .pyt
- C) .pyth
- D) .pt

Respuesta: A

**3.** ¿Qué palabra se usa para crear una condición en Python?
- A) if
- B) when
- C) condition
- D) check

Respuesta: A

**4.** En Python, ¿cómo se declara una lista?
- A) lista = {}
- B) lista = []
- C) lista = ()
- D) lista = < >

Respuesta: B

**5.** ¿Qué hace el operador % en Python?
- A) Calcula porcentaje
- B) Divide dos números
- C) Devuelve el residuo de una división
- D) Multiplica

Respuesta: C

**6.** Python es un lenguaje compilado y no interpretado. (Verdadero/Falso)
- A) Verdadero
- B) Falso

Respuesta: B, Falso. Python es interpretado.

**7.** ¿Qué ciclo se usa para repetir código un número determinado de veces?
- A) for
- B) repeat
- C) loop
- D) while only

Respuesta: A

**8.** ¿Qué valor devuelve la expresión 3 > 5?
- A) True
- B) False
- C) 0
- D) Error

Respuesta: B

**9.** ¿Cómo se pide un dato al usuario por teclado?
- A) input()
- B) get()
- C) read()
- D) scan()

Respuesta: A
