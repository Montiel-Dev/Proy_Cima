1.- ¿Qué comando se usa para consultar datos de una tabla? 
A) INSERT 
B) DELETE 
C) SELECT 
D) UPDATE 
Correcta: C 

2.- ¿Qué comando agrega un nuevo registro a una tabla?
A) INSERT INTO 
B) SELECT 
C) DROP 
D) ORDER BY 
Correcta: A 

3.- ¿Qué cláusula se usa para filtrar resultados? 
A) ORDER BY 
B) LIMIT 
C) JOIN 
D) WHERE Correcta: D

4.- ¿Qué cláusula ordena los resultados de una consulta?
A) GROUP 
B) ORDER BY 
C) WHERE 
D) FROM 
Correcta: B 

5.- ¿Para qué sirve una llave primaria? 
A) Identificar de forma única cada registro 
B) Guardar contraseñas 
C) Borrar una tabla 
D) Unir dos bases de datos 
Correcta: A 

6.- ¿Qué comando modifica registros que ya existen? 
A) MODIFY 
B) UPDATE 
C) CHANGE 
D) ALTER 
Correcta: B 

7.- ¿Qué comando elimina registros de una tabla? 
A) REMOVE 
B) DROP ROW 
C) DELETE
D) CLEAR 
Correcta: C 

8.-¿Qué hace LIMIT 10 en una consulta? 
A) Muestra solo los primeros 10 resultados 
B) Borra 10 registros 
C) Ordena 10 registros 
D) Crea 10 tablas Correcta: A

9.- ¿Qué se usa para combinar datos de dos tablas? 
A) LIMIT 
B) WHERE
C) COUNT 
D) JOIN 
Correcta: D 

10.- ¿Qué función cuenta cuántos registros hay?
A) SUM
B) COUNT 
C) MAX 
D) AVG 
Correcta: B
