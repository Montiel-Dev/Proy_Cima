Proyecto examen de cima
# CIMA Quiz

## Descripción
Aplicación web local para evaluar conocimientos de HTML,
MySQL y Python mediante preguntas de opción múltiple.

## Objetivo
Seleccionar preguntas, calificar respuestas automáticamente
y registrar los resultados de cada intento.

## Tecnologías
- HTML5 y CSS
- Python 3.10 o superior
- MySQL 8
- mysql-connector-python
